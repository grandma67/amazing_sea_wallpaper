# Lessons and gotchas

Things that bit us, split by topic in `lessons/`: read PROCESS.md on every task, then the files for
what you're touching. Workflow rules: CLAUDE.md; tool usage and shell gotchas: TOOLS.md "Gotchas";
open bugs: KNOWN_ISSUES.md. Write a new lesson as a rule for the next thing of its kind, not as the
story of this one, in the file (and section) it belongs to.

| File | Sections | Read when |
|---|---|---|
| [lessons/PROCESS.md](lessons/PROCESS.md) | Process; Debugging approach | every task |
| [lessons/SCRIPTS.md](lessons/SCRIPTS.md) | Scripts and tools; Randomness, params and tests; Page | writing or running scripts, params, choices, tests; console or page messages |
| [lessons/SHADERS.md](lessons/SHADERS.md) | Shaders (GLSL) | any shader edit |
| [lessons/LIGHT.md](lessons/LIGHT.md) | Light and exposure; Colours from photos | lighting, exposure, colours, tints |
| [lessons/SKY.md](lessons/SKY.md) | takram sky, clouds, post; Night sky; Storms and sky objects | sky, clouds, post, stars, moon, aurora, lightning, fog |
| [lessons/OCEAN.md](lessons/OCEAN.md) | Sea and surf | water, waves, foam, reflection |
| [lessons/COAST.md](lessons/COAST.md) | Coast and terrain; Snow, ice and big shapes | terrain, shore, tides, sand, rock, snow, sea ice |
| [lessons/PROPS.md](lessons/PROPS.md) | Seasons and plants; Placement; Meshes | plants, animals, debris, any instanced prop or mesh |

Older references of the form `LESSONS.md "Section"` (changelog) name a section in one of these
files: see the table.
